# HOME FOR CHRISTMAS — Build Spec (5 hours, 3 builders + coding agents)

Personalised Coca-Cola "Holidays Are Coming" playable ad. Judge scans a QR, answers 3 questions, and the Coke truck rolls into a live-generated Christmas market in *their* hometown (Reactor). They get a personalised video Christmas card where Santa says their name (VEED Fabric). The projector shows a world map of every judge's Christmas plus an AI-reasoned media plan. Backend runs on Modal.

Sponsors, load-bearing:
- **Reactor** (`reactor/helios` model, JS SDK) — live interactive Christmas-market video, steered by prompt changes from the user's answers and gestures.
- **VEED** (`veed/fabric-1.0` via fal.ai) — image + audio → talking video. Used for the personalised Santa/Coke-driver Christmas card ("Merry Christmas, Seva, from everyone in Tallinn").
- **Modal** — the entire backend: FastAPI app (`@modal.asgi_app()`), state in `modal.Dict` (no database), background jobs for VEED/fal generation, secrets.

## 0. Stack (final — do not change)

| Layer | Choice | Why |
|---|---|---|
| Frontend | **Vite + React + TypeScript + Tailwind**, deployed on **Vercel** | Static SPA, zero server config, 2-min deploy, public HTTPS for phones/QR |
| Backend | **Modal** — one `backend/app.py` with FastAPI mounted via `@modal.asgi_app()` | Sponsor; one command deploy (`modal deploy`), gives a public URL, secrets built in |
| State | **`modal.Dict.from_name("hfc-state", create_if_missing=True)`** | No DB to set up. Keys: `session:{id}`, `events:{id}`, `sessions` (list of ids) |
| Realtime | **Polling** — dashboard `GET /api/state` every 1.5s | Simplest thing that works on venue wifi; no websockets to debug |
| Live video | **Reactor JS SDK** `@reactor-team/js-sdk`, model `reactor/helios`, token minted by Modal `POST /api/reactor-token` | Official flow: browser gets short-lived JWT from your server |
| Generated video | **fal.ai** Python client `fal-client` on Modal → `veed/fabric-1.0` (image+audio→video), `fal-ai/flux/schnell` (hometown still image), `fal-ai/elevenlabs/tts/turbo-v2.5` or OpenAI TTS (Santa voice) | One API key (FAL_KEY) covers VEED + image + voice |
| LLM | **OpenAI `gpt-4o-mini`** (prompt building, reasoning) | Fast, cheap, JSON mode |
| QR | `qrcode.react` | — |
| Map | `react-simple-maps` (+ `d3-geo`) with a static world topojson | No API key |
| Cities | Static `cities.json` (top ~300 cities: name, country, lat, lng, landmark) generated by the LLM in minute 1 | No geocoding API |

## 1. Shared contracts (write these first, everyone codes against them)

### Session object (stored in Dict at `session:{id}`)
```json
{
  "id": "a1b2c3",
  "name": "Seva",
  "city": "Tallinn", "country": "Estonia", "lat": 59.43, "lng": 24.75, "landmark": "Town Hall Square",
  "company": "friends",           // family | friends | partner | solo
  "smell": "mulled",              // mulled | gingerbread | pine | chestnuts
  "scene_prompt": "…",            // built by /api/scene
  "image_url": null,              // flux still of the market (for Reactor set_image + card)
  "card_status": "none",          // none | pending | ready | failed
  "card_url": null,               // VEED Fabric video URL
  "step": "questions",            // opened | questions | scene | truck | card | done
  "truck_hold_ms": 0,
  "gifts": 0,
  "shared": false, "cta": false,
  "created_at": 1734000000
}
```

### Endpoints (Modal FastAPI, all JSON, CORS `*`)
| Method | Path | Body → Response |
|---|---|---|
| POST | `/api/session` | `{}` → `{id}` |
| POST | `/api/answers` | `{id, name, city, company, smell}` → full session incl. `scene_prompt`, `lat/lng/landmark` (looks up cities.json server-side; LLM fallback for unknown city). Kicks off background `make_card(id)` job. |
| POST | `/api/event` | `{id, type, value?}` → `{ok}`. Types: `opened, look, walk, truck_hold(ms), gift, share, cta, drop`. Updates `step`, `truck_hold_ms`, `gifts`, `shared`, `cta`. |
| POST | `/api/reactor-token` | `{}` → `{jwt}` (calls `https://api.reactor.inc/tokens` with header `Reactor-API-Key`) |
| GET | `/api/session/{id}` | → session (phone polls this for `card_url`) |
| GET | `/api/state` | → `{sessions: [...all sessions...], counts: {scans, playing, cards, shares, cta}}` (dashboard polls) |
| POST | `/api/insight` | `{}` → `{headline, reasoning: [step…], segments, media_plan, cities_to_localise}` (LLM over all sessions) |
| POST | `/api/seed` | `{n: 20}` → creates fake sessions with cards pointing at a pre-made sample card URL |
| POST | `/api/reset` | → clears Dict |

### Reactor commands used (model `reactor/helios`)
- wait for `statusChanged === "ready"`
- `sendCommand("set_prompt", { prompt })` — initial scene and every steer
- `sendCommand("set_image", { image: ref })` — optional: anchor on the flux hometown still (`uploadFile` first)
- `sendCommand("start", {})`
- render: `on("trackReceived", (name, track) => name === "main_video" && (video.srcObject = new MediaStream([track])))`

Steering = re-sending `set_prompt` with a modified prompt:
- look left/right (tilt or drag) → append `", camera panning left"` / `"right"`
- walk (swipe up) → `", walking forward through the market"`
- truck hold → `", a glowing red Coca-Cola Christmas truck approaching with bright lights, snow falling harder"`
- gift tap → `", a smiling person holding a Coca-Cola bottle, warm glow"`

## 5. Risks → mitigations
- Reactor GPU wait/latency → 6s timeout → flux still with Ken-Burns + snow; `hfc_no_reactor` kill switch; pre-connect Reactor during the questions screen to hide startup time.
- VEED card slow → 480p, precached judges' cards, "Santa is recording…" holding screen, `SAMPLE_CARD_URL` on failure.
- Venue wifi → hotspot; polling not websockets; Vercel + Modal are both CDN-fronted.
- iOS gyro → request permission inside the tap gesture; drag fallback.
- Audio autoplay → jingle starts on "Tap to open".
- Modal cold start → keep `min_containers=1` on `fastapi_app` (`@app.function(..., min_containers=1)`) for the demo hour.
- Unknown city → LLM fallback lookup; never block the flow.
- Trademark → slide footer: "Concept demo for Coca-Cola. Not affiliated."
